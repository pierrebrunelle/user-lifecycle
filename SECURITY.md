# Security policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 0.7.x   | yes       |
| < 0.7   | no        |

## Reporting a vulnerability

Report a vulnerability through [GitHub private security advisories](https://github.com/pierrebrunelle/walk-the-job/security/advisories/new).

Include what the issue is, how to reproduce it, and any mitigation you already see.

Please leave public issues for bugs in the session procedure.
